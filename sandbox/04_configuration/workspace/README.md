# workspace/

Your safe, disposable practice area for Phase 04 — scratch config files,
test loaders, and multi-environment practice sets from Lessons 01–04.

## How this differs from Phase 04's real-repo work

Lesson 05's capstone (`sandbox/_templates/CONFIGURATION_CONVENTION.md`)
and the practical assessment's Checkpoint 4 scaffolding are **real,
committed work** on the actual `Learn-DE` repository via feature branches,
per the Repository Usage Policy — deliberate, not a mistake. This folder
is for the earlier lessons' throwaway practice: config files you're
iterating on before anything is meant to last.

## What NOT to put here

- Anything that should persist as a graded artifact — evidence belongs in
  [`../notes/`](../notes/README.md).
- Real credentials or `.env` files with real values.

## Version control

Everything under `workspace/` except this README is gitignored — see the
root [`.gitignore`](../../../.gitignore).
