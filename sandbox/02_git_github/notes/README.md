# notes/

Your personal, evidence-focused space for Phase 02.

## What goes here

- **Evidence files** (required for scoring): `lesson_NN_evidence.md` for
  each lesson's guided and independent exercises, plus
  `assessment_evidence.md` for the practical assessment. Use
  [`evidence_template.md`](evidence_template.md) as the format.
- **Your own running notes**: commands you keep forgetting, GitHub CLI vs.
  web UI preferences you're forming, questions to revisit.
- **`phase02_score.md`**: your self-scored rubric worksheet (template in
  [`../assessment/rubric.md`](../assessment/rubric.md)).

## What doesn't go here

- Generated runtime artifacts (scratch files, temporary branches' working
  copies) — those belong in [`../workspace/`](../workspace/README.md).
- Real secrets, tokens, or private key contents — evidence may reference a
  fake/practice secret's *pattern*, never a real credential.

## Why evidence matters here

Scoring (see [`../assessment/rubric.md`](../assessment/rubric.md)) is
based on what's actually in these files — real commands, real terminal
output, real PR/Issue/Release URLs and text — not on whether a lesson's
completion checklist got checked.
