# Phase 02 Scoring Rubric (100 points)

Every category is graded on **evidence in `notes/`**, not on checked
boxes. There is no quiz — see [`README.md`](README.md) for the one
practical assessment this rubric scores.

## Guided Exercises — 25 points

12 lessons × ~2 points each (24), + 1 point for consistently confirming
each exercise's stated Validation criterion with real output.

- **2**: Real commands, real output, matches the Validation criterion, at least a one-sentence explanation.
- **1**: Present but thin — validation not explicitly confirmed, or explanation missing.
- **0**: No evidence, or a checklist with no real output behind it.

## Independent Exercises — 30 points

12 lessons × ~2.5 points each, scored 0–2.5 per lesson:

- **2.5**: Goal fully met, own design choices (not copied from the guided exercise), real validation output, constraints respected (temporary branches deleted where required, no real secrets used, no force-push to `main`).
- **1.5**: Goal partially met, or thin on explanation/validation.
- **0**: Not attempted, or no evidence submitted.

## Practical Assessment — 35 points

The one real-repository assessment (see [`README.md`](README.md)):

| Category | Points | What's evaluated |
|---|---|---|
| Branching + commit hygiene | 6 | Real feature branch, atomic and well-organized commits grouping the actual backlog sensibly |
| Interactive rebase cleanup | 4 | The branch's history reads as an intentional story before the PR is opened |
| Pull request + merge | 5 | Real PR description, real self-review, deliberate and justified merge strategy |
| Controlled merge conflict resolution | 5 | Conflict resolved by understanding both real sides, not guessing; nothing real lost |
| Issues, labels, project organization | 5 | Real, actionable issues; a real, sensible label taxonomy actually applied |
| Release | 4 | Real tag + Release with genuine, accurate notes |
| Secret management (audit + case study) | 4 | Real hygiene audit; real or properly-practiced incident case study; rotation-first reasoning demonstrated |
| Repository maintenance | 2 | Clean final `git status`, readable `git log --graph`, no leftover practice branches |

## Documentation and Reflection — 10 points

| Item | Points |
|---|---|
| `notes/` populated with real evidence for at least 10 of 12 lessons | 5 |
| `reflection.md` thoughtfully completed (specific, not generic) | 5 |

## Completion Criteria

| Score | Outcome |
|---|---|
| **80–100** | Pass — continue to the next phase in your Progress Tracking plan. |
| **70–79** | Review the weakest categories, redo only those, reassess. |
| **Below 70** | Repeat the weakest lessons and exercises in full, then re-attempt the assessment. |
