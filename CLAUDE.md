# Claude Instructions

This repository is a personal Data Engineering learning repository.

## Repository Rules

- Treat `ref roadmap/` as read-only reference material.
- Never modify, move, rename, or delete files under `ref roadmap/`.
- Use `sandbox/` for exercises, experiments, code, infrastructure, and projects.
- Read `docs/DE_LEARNING_PATH_REQUIREMENTS.md` before designing or modifying the learning path.
- Follow the architecture-first learning direction defined in that document.
- Do not generate complete exercise solutions unless explicitly requested.
- Prefer guided exercises, starter templates, TODOs, validation criteria, and explanations.
- Prefer tools that run locally in Ubuntu/WSL.
- Prefer free, open-source, or free-tier technologies.
- Never commit passwords, tokens, API keys, credentials, `.env` files, private keys, or secrets.
- Before creating many folders or files, propose the plan and wait for approval.
